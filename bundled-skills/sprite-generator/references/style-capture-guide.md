# Style Capture Guide

When a user provides a style reference, describe the style before generating any sprites. Capture:

1. Perspective/camera angle.
2. Proportions and silhouette language.
3. Edge treatment and outlines.
4. Lighting and material style.
5. Palette, saturation, contrast.
6. Shadow policy.
7. Background/removal strategy.
8. Scale/readability target.

Turn that into a short reusable style lock such as:

> Soft toy-like 3D-rendered chibi game sprites, rounded forms, large expressive eyes, clean saturated colors, gentle top-left studio lighting, no outlines or only very soft edges, flat chroma green background, transparent final asset, no floor shadows, no labels.

Use that style lock in every base/state/animation prompt. A generation that only loosely resembles the style should be repaired before packaging.
